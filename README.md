# ZAY-Bot

بوت Discord خفيف لإدارة السيرفرات والميزات العامة.

الوصف
------
ZAY-Bot هو بوت Discord مكتوب بهدف تقديم أدوات إدارية وترفيهية للسيرفرات: إدارة الأعضاء، نظام تكت، تقديمات، اقتراحات، إعدادات ترحيب، وغير ذلك. هذا الريبو يحوي كود البوت ويمكن توسيعه ليرتبط بلوحة تحكم خارجية (Dashboard) وقاعدة بيانات.

الميزات (مبدئية)
-----------------
- تسجيل الدخول عبر Discord OAuth2 (عند ربط Dashboard).
- إدارة الأعضاء (Kick/Ban/Warn).
- نظام تذاكر (Tickets).
- نظام تقديمات واقتراحات.
- سجلات إدارية وأحداث.
- قابل للتطوير لربط لوحة Dashboard (VEXORA PANEL مثلاً).

المتطلبات
---------
- Node.js (v16+ أو النسخة الموصى بها في المشروع)
- npm أو yarn
- PostgreSQL (اختياري وفق إعدادات المشروع)
- Redis (اختياري للكاش والجلسات)

التركيب والتشغيل محليًا
-----------------------
1. استنخِب المستودع:

```bash
git clone https://github.com/w9zpbdyyjt-cloud/ZAY-Bot.git
cd ZAY-Bot
```

2. ثبّت الاعتمادات:

```bash
npm install
# أو
# yarn install
```

3. أنشئ ملف إعدادات مثال (لا تضف أسرارك هنا):

```
cp .env.example .env
```

4. عدّل القيم في `.env` مع إضافة القيم الحقيقية على المضيف أو في GitHub Secrets — لا ترسل أي توكن في الدردشة.

المتغيرات البيئية المطلوبة (أمثلة — لا تضع القيم هنا في الريبو):

```
DISCORD_CLIENT_ID=YOUR_CLIENT_ID
DISCORD_CLIENT_SECRET=YOUR_CLIENT_SECRET
DISCORD_BOT_TOKEN=YOUR_BOT_TOKEN
DATABASE_URL=postgresql://user:pass@host:5432/dbname
JWT_SECRET=some_random_secret
REDIS_URL=redis://user:pass@host:6379
```

ملاحظة أمان: إذا تسرب توكن البوت، قم فورًا بإعادة توليد التوكن من Discord Developer Portal وغيّر القيم في أماكن التخزين.

تشغيل البوت
-----------
- للتشغيل في وضع التطوير:

```bash
npm run dev
```

- للتشغيل في الإنتاج:

```bash
npm start
```

أو استخدم Docker/Docker Compose إن وُفِّر ملف التكوين المناسب.

إضافة لوحة تحكم (Dashboard)
---------------------------
يمكن ربط البوت بلوحة تحكم خارجية عبر:
- إضافة واجهة API في البوت تتعامل مع تغييرات الإعدادات (مستحسَن)
- أو السماح للـDashboard بتخزين الإعدادات في قاعدة بيانات يقرأها البوت عند الحاجة

يرجى مراجعة ملفات الكود والـREADME الخاص بالـDashboard عند الربط.
